# eto — Arch / bspwm / Black Tiffany

Рабочее окружение ThinkPad P50, дискретная NVIDIA 470, чёрная тема с акцентами Tiffany. Оба установленных ядра и обычный сон проверены; основное — Linux LTS.

## Структура

```text
dotfiles/
├── configs/              пользовательские настройки
│   └── etc/              несекретные системные настройки этого ноутбука
├── scripts/
│   ├── bin/              ~/bin
│   ├── local-bin/        ~/.local/bin
│   ├── system/           системные helpers и очистка старых модулей
│   └── diagnostics/      сохранённые обходные способы для диагностики
├── themes/               GTK Black-Tiffany и SDDM Black Tiffany
├── patches/nvidia470/    проверенные патчи совместимости
├── docs/                 инструкции, выбранные пакеты, манифесты
├── install.sh            пакеты и пользовательские конфиги
├── restore-system.sh     восстановление системной части; по умолчанию только проверка
└── maintain-system.sh    защита сна при обновлениях и утверждённая очистка
```

## Текущая система

Профиль автоустановки: **reverse engineering / malware analysis**. Установленные инструменты пентеста сохраняются для CTF; в установщике их можно выбрать отдельно. BlackArch автоматически не подключается. Существующий репозиторий на рабочей системе автоматически не отключается. Тяжёлые Windows-инструменты анализа предназначены для отдельной VM.

Полный install.sh на уже настроенной системе запускать не нужно. Предыдущая системная очистка завершена. Удаление только 15 выбранных приложений проверяется командой `bash scripts/maintenance/remove-selected-apps --check`, применяется с `sudo bash scripts/maintenance/remove-selected-apps --apply`. Старое имя retire-pentest оставлено совместимым и тоже не удаляет CTF-инструменты. Общие зависимости и VM сохраняются.

Объединённое руководство: [ARCH-RE-MALWARE-GUIDE.md](docs/ARCH-RE-MALWARE-GUIDE.md). Его процедуры новой разметки предназначены только для чистой установки. [История обслуживания](docs/MAINTENANCE.md).

Документация и история: ~/Documents/Workstation/2026-10-16/README.md. Старые пути Documents/dotfiles-map и system-*-2026-10-16 оставлены для совместимости.

## Восстановление

[RESTORE.md](docs/RESTORE.md). Системная часть привязана к этому ноутбуку и UUID root: проверка остановится на другой машине. Секреты, браузерные профили, Obsidian vault и диски VM в репозиторий не включены. Для них нужна отдельная резервная копия.

Ни очистка, ни установщик не публикуют изменения в Git и не создают commit автоматически.
