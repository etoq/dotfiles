# Thinkfan: одна команда для двух режимов

**Otter → `fan`** или **`fan-toggle`** в терминале переключает текущий профиль:
обычный → тихий → обычный. Успех сопровождается уведомлением с новым режимом.
`fan-toggle --status` показывает текущий режим без изменений и без запроса прав.

Для изменения `/etc/thinkfan.conf` нужны права администратора. В Otter открывается
штатное окно Polkit с запросом пароля; в терминале используется sudo.
Пароли скрипт не получает и не сохраняет, правил беспарольного доступа не добавляет.

Переключатель использует существующие `/etc/thinkfan-normal.conf` и
`/etc/thinkfan-silent.conf`; температурные кривые не меняет. Профиль определяется
сравнением разобранного YAML, поэтому комментарии и форматирование не мешают.
Если текущий конфиг отличается от обоих профилей, переключение отменяется.

Перед применением проверяются структура уровней, гистерезис, одинаковые
интерфейсы двух профилей, доступность датчиков и работающий Thinkfan.
Конфиг заменяется атомарно, исходник сохраняется в
`/var/backups/thinkfan-profile-ДАТА-ВРЕМЯ-*/thinkfan.conf`.

Вместо остановки вентиляционного демона используется `systemctl reload thinkfan`.
Подтверждение: тот же процесс записал в журнал получение SIGHUP и затем
температуры/уровень вентилятора без ошибки перечитывания. Одного успешного
возврата systemctl недостаточно. При ошибке или отсутствии подтверждения
восстанавливается прежний файл и запрашивается его перечитывание; неудача
отката также явно сообщается. Прямых команд остановки вентилятора нет.

Старые отдельные Fish-функции `fan-silent` и `fan-normal` перенесены в
`~/.local/state/thinkfan-toggle-migration/` и больше не нужны. Если функция уже
была загружена в открытую оболочку Fish, её можно забыть командой
`functions -e fan-silent fan-normal` или открыть новый терминал.

Семь изолированных тестов проверяют оба направления, резервную копию, откат,
неизвестный профиль, комментарии YAML, некорректные пороги и подтверждение
перечитывания. Реальные вентиляторы тестами не переключаются.
