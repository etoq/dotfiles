# Минималистичный календарь

Win+Shift+K открывает календарь, повторное нажатие или Esc закрывает его.
Нажмите дату и пишите в поле под месяцем. Сохранение автоматически через
полсекунды после ввода, а также перед сменой даты или закрытием.
Точка рядом с числом означает, что на этот день есть заметка.
Чтобы удалить заметку, очистите поле. Стрелки меняют месяц, «Сегодня» возвращает
текущую дату. Enter внутри поля добавляет строку. Окно не захватывает клавиатуру.

Текстовые файлы UTF-8: `${XDG_DATA_HOME:-~/.local/share}/tiffany-calendar/notes/YYYY-MM-DD.txt`.
Заметки хранятся отдельно от dotfiles, локально, без облака и напоминаний.
Запись атомарная; при ошибке сохранения переход/закрытие отменяется, текст остаётся
в поле, статус сообщает об ошибке. Не редактируйте тот же файл извне одновременно.
Предыдущий calcurse и его данные не удаляются. На момент замены apts и todo были пусты.

Зависимости: python, python-gobject, gtk3. Скрипт: `~/.local/bin/tiffany-calendar`.
