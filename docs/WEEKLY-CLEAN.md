# Ручная очистка Arch

Otter → `clean` → Enter. Открывается терминал; sudo запрашивается для системного
кэша и журналов. В конце показан результат, окно закрывается по Enter.
Запускай примерно раз в неделю. Отдельная месячная команда не нужна.
Таймеры и автозапуск для этого скрипта не создаются.

При каждом запуске:

- Pacman и архивы пакетов в `~/.cache/yay`: сохранить по две последние версии
  каждого пакета, включая удалённые пакеты, и все архивы моложе семи дней.
- Миниатюры: удалить только обычные файлы, которые не читались и не менялись
  как минимум 14 дней.
- `~/Downloads/AyuGram Desktop`: удалить только обычные файлы без чтения и изменений
  за семь дней; ссылки и прочие папки Downloads не затрагиваются. Пустые каталоги
  в загрузках остаются. Данные аккаунта и переписки AyuGram не затрагиваются.
- Корзины `~/.local/share/Trash` и `/vms/.Trash-1000`: удалить объекты, выброшенные
  более 30 дней назад, по `DeletionDate` из `.trashinfo`. Недавно выброшенный
  старый файл сохраняется. Для старых объектов-папок удаляется всё их содержимое,
  ссылки наружу не обходятся. Объекты с повреждёнными метаданными сохраняются.
- Показать пакеты-сироты для информации, без удаления.

При первом запуске и затем раз в 30 дней после успешной месячной очистки:

- pip: удалить обычные файлы кэша без обращений за 30 дней.
- uv: штатный `uv --offline --no-config cache prune`, без `--force`/`--ci`.
- npm: штатный `npm cache verify`, без полного сброса кэша.
- systemd journal: удалить архивные журналы старше 30 дней. Активный журнал
  не ротируется принудительно; `/var/log/pacman.log` сохраняется.

Не затрагиваются исходники и рабочие каталоги сборок AUR, проекты, Cargo target,
браузерные профили, остальные Downloads, недавно выброшенные файлы, VM, ядра/драйверы, пакеты, Snapper,
резервные копии и `/tmp`. Полное удаление `~/.cache` не выполняется.
Символические ссылки и файлы с несколькими жёсткими ссылками не удаляются
собственным обработчиком кэшей. Для pacman используется его штатный paccache.

Скрипт отказывается работать, если обнаружено обновление/сборка, и использует
общую блокировку с upd/yupd. Ошибка отдельного действия отражается в итоге;
при ошибке дата успешного месячного запуска не обновляется.
Нужны уже установленные Python, pacman-contrib, sudo; uv/npm необязательны.

Из терминала:

```sh
weekly-clean --dry-run   # просмотр без sudo и удаления
weekly-clean --apply    # очистка
clean                   # тот же запуск из Fish
```

Отчёт последнего выполнения: `~/.local/state/weekly-clean/last-run.json`.
Изменение свободного места — измерение всей файловой системы за время запуска,
поэтому параллельные записи и снимки Btrfs могут влиять на результат.
Архивы пакетов сверх политики удаляются окончательно: это очистка кэша,
а не создание новой резервной копии. Выбранные старые загрузки AyuGram
и старое содержимое корзин также удаляются окончательно при запуске `clean`.

Предыдущий скрипт и настройки запуска сохранены в
`~/.local/state/weekly-clean/setup-backup/`.

Правила paccache: https://man.archlinux.org/man/paccache.8
