# Сохранение окружения · 2026-11-13

Этот репозиторий сохраняет несекретные настройки и сценарии восстановления,
но не является образом диска или полной резервной копией пользовательских данных.

## Что сохранено

- AwesomeWM, Polybar, Kitty, Fish, Otter, Picom, Yazi и Neovim — существующие
  конфиги и скрипты. Исправление открытия текстов: пользовательский nvim.desktop
  запускает Kitty → nvim, Yazi имеет явное правило для .txt/.TXT.
- G435 для Codex voice: configs/alsa/asoundrc; установщик подключает ~/.asoundrc.
  Выбор audio.microphone в частном ~/.codex/config.toml повторяется вручную
  по docs/CODEX.md. Длительный голосовой сеанс остаётся отдельной проверкой.
- Ручной weekly-clean, его тесты и входы из Fish/Otter; фактическая очистка
  не выполняется при сохранении репозитория или проверке установщика.
- warpd: конфиг, памятка Win+F9, патч Tiffany-стрелки и рецепт сборки
  configs/warpd/README.md. База: v1.3.5,
  effea402ec8668bb2bc5c5117800d16d0d9d349a.
  Бинарник собирается отдельно; автозапуск пока не включён.
  Системный Caps+HJKL → стрелки сохранён в configs/etc/keyd/default.conf.
- Picom: только для warpd исключены blur, тени, скругление и fading.
- Текущие пользовательские настройки Flameshot, LocalSend и wallpaper.
  Различие wallpaper было в кодировании PNG, пиксели совпали.
- Актуальные несекретные /etc/nftables.conf и /etc/tlp.conf перенесены
  в payload восстановления. Отсутствующий сейчас 99-lid-lock.conf исключён
  из списка применения restore-system.sh; исторический файл сохранён в Git.
- docs/packages-explicit.txt и docs/packages-aur.txt обновлены по pacman.
  Это имена установленных пакетов, а не архивы пакетов или гарантия доступности
  прежних версий в репозиториях.

## Проверки

Read-only audit-dotfiles.py: 159 соответствий установщика, 0 различий.
restore-system.sh --check: 33 конфигурации, 5 helpers, тема SDDM;
проверяется наличие payload и идентичность машины, ничего не применяется.
Сравнение этих /etc-файлов с живой системой: содержимое совпало,
кроме незначащих пробелов в последней строке fstab.

Прошли 10 тестов weekly-clean на временных данных и 2 теста безопасности
установщика. Проверены синтаксис shell, TOML/JSON и пользовательский desktop entry.
Патч warpd и сборка/отрисовка ранее проверены на отдельном Xvfb+Picom.
Это не испытание полного восстановления на чистой машине.

## Что восстанавливается отдельно

Пароли, SSH-ключи, keyring, токены, приватные настройки прокси, браузерные
профили, личные заметки, содержимое проектов и VM в публичный Git не помещаются.
Для них нужна отдельная приватная резервная копия по текущему plan.json.
Vimium устанавливается из Mozilla Add-ons; его активность проверена локально
(2.4.2), профиль браузера не публикуется.

Проект workstation хранится в отдельном локальном Git и не имеет remote;
его отчёты и файлы отката в этот публичный репозиторий не копируются.
Не запускайте старые миграционные скрипты для повторения уже завершённых работ.
Общий install.sh не запускался при этой сверке. Для проверки связей используйте
bash install.sh --check; применение системного payload — отдельная операция.
