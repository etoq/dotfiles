# Работа, отдых и таймер

Открыть: **Win+Shift+R**, `study` в терминале или команда `study` в Otter.
Это консольное приложение без новых внешних зависимостей.

- **1** — работа с аналитикой.
- **2** — отдых с отдельной аналитикой.
- **3** — обратный отсчёт без аналитики; введите минуты, `25m`, `90s` или `1h`.
- **Пробел** — пауза учёта.
- **D / W / M / A** — день / последние 7 дней / текущий календарный месяц / последние 30 дней.
- **Стрелки вверх/вниз** — прокрутка дней.
- **Q / Esc** — закрыть интерфейс. Выбранный режим работы/отдыха продолжит считаться
  в фоне. Если открыт таймер, закрытие интерфейса отменяет его; учёт остаётся на паузе.

Время показывается в десятичных часах: **1.50 ч = 1 час 30 минут**.
Работа и отдых всегда считаются отдельно. После окончания таймера режим учёта
не возобновляется автоматически; приходит уведомление.

Команды без интерфейса:

```sh
study work                 # учитывать работу
study rest                 # учитывать отдых
study pause                # приостановить
study status               # режим и состояние сборщика
study report day
study report week
study report month
study report 30 --json     # секунды по дням и периодам для экспорта
study timer 25m            # отдельный таймер без аналитики
```

Фоновая служба `study.service` запускается при входе в Awesome или bspwm.
В новом сеансе учёт начинается на **паузе** — выберите работу или отдых.
Открытое окно программы для сбора не требуется.

Сборщик проверяет активность раз в 5 секунд. После 5 минут без клавиатуры/мыши
учёт останавливается до нового ввода; эти первые 5 минут входят в выбранный режим.
Блокировка i3lock/betterlockscreen, неактивный сеанс и сон исключаются.
Смена режима/блокировка/пробуждение могут пропустить до одного интервала проверки.
Просмотр видео сам по себе не продлевает учёт. Для чтения без ввода можно
увеличить `--idle-seconds` в пользовательском override службы (30–3600 секунд).
Трекер определяет активность, а не продуктивность: содержание занятий выбираете вы.

Хранятся только интервалы начала/конца и режим work/rest, без названий приложений,
сайтов, текста и кодов клавиш. Локальная база:
`~/.local/state/study/activity.sqlite3` (0600; приватная папка 0700).
Прошлые дни до установки не восстанавливаются. История не отправляется в облако.
При резервном копировании SQLite учитывайте WAL: используйте SQLite backup API
или предварительно остановите службу; простого копирования одного файла недостаточно.

Проверка службы: `systemctl --user status study.service`.
Журнал: `journalctl --user -u study.service`.
Отключение: `systemctl --user stop study.service`; для постоянного запрета
`systemctl --user mask study.service` (отмена: `unmask`).
