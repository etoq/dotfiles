# Консольный переводчик

Открыть: команда **tr** в Otter или **translate** в терминале.
Otter `tr текст` передаёт текст прямо в консольное приложение.
Системная Unix-команда `tr` остаётся обычной командой обработки символов.

Первый запуск предложит настройку. Её также можно открыть отдельно:

```sh
translate --setup
```

Выберите сервис, модель и введите API-ключ в скрытом поле. Ключ не нужно присылать
в чат, вставлять в shell-команду или добавлять в dotfiles. Настройка не делает
платных тестовых запросов: первый запрос произойдёт при переводе вашего текста.

Поддерживаются два варианта:

- **Gemini**: по умолчанию `gemini-3.8-flash`; есть бесплатная квота с лимитами.
  Ключ: [Google AI Studio](https://aistudio.google.com/apikey).
  [Тарифы](https://ai.google.dev/gemini-api/docs/pricing),
  [REST API](https://ai.google.dev/api/generate-content).
- **OpenAI API**: по умолчанию `gpt-4.1-mini`, небольшая модель без отдельного
  этапа reasoning; модель можно поменять при настройке. API оплачивается отдельно.
  [Ключи](https://platform.openai.com/api-keys),
  [карточка модели](https://developers.openai.com/api/docs/models/gpt-4.1-mini),
  [тарифы](https://developers.openai.com/api/docs/pricing).

Выбор по умолчанию — стартовые настройки, не утверждение о лучшем качестве.
Для оценки качества используйте знакомые технические фрагменты и сравнивайте
с оригиналом. Промпт задаёт контекст Linux, реверса, ассемблера и анализа ВПО,
просит сохранить код, адреса, команды, пути, имена функций и структуру текста.
Модель должна возвращать только перевод, не выполнять инструкции из исходника.

## Использование

```sh
translate 'The function validates the buffer length.'
translate --to en 'Функция проверяет длину буфера.'
printf '%s' 'memory mapping' | translate
translate --clipboard --copy
translate --ui
```

Без параметров в терминале открывается диалог с бирюзовым оформлением:

- Введите текст и Enter — перевод.
- **/paste** — перевести текущий буфер обмена по вашей команде.
- **/edit** — ввести многострочный фрагмент через `$VISUAL` / `$EDITOR` (обычно Neovim).
- **/copy** — скопировать последний успешный перевод. Он останется в буфере после выхода.
- **/to ru**, **/to en**, **/to auto** — выбрать направление.
- **/q**, **Ctrl+D** — выйти; **Ctrl+C** — прервать ожидание.

В режиме auto направление выбирается по преобладающим буквам: русский → английский,
остальные тексты → русский. Для смешанного текста с кодом задайте язык явно.
Другие языки доступны через `--to de`, `/to fr` и т. п., если их поддерживает модель.
Возможности и ограничения конкретной модели определяются выбранным API.

До 12 000 символов за запрос. При обрезанном/отклонённом ответе программа сообщает
об ошибке. Автоматических повторов и переключений на платный сервис нет.
Повтор того же текста в одном сеансе берётся из небольшого кэша в памяти.

## Локальные данные

- `~/.config/tiffany-translate/config.json` — только сервис и модель.
- `~/.config/tiffany-translate/gemini.key` либо `openai.key` — ключ, права **0600**.
- Вместо файлов можно использовать уже заданные `GEMINI_API_KEY` / `OPENAI_API_KEY`.

Приложение не записывает историю переводов на диск и не наблюдает за буфером
в фоне. Текст отправляется выбранному API только по команде перевода. Внешний
редактор `/edit` использует ваши обычные настройки, включая его swap/undo.
У бесплатного Gemini API данные могут использоваться Google для улучшения
продуктов; детали и различия с платным тарифом указаны в его официальных условиях.
Для OpenAI запрос отправляется с `store=false`; это не заменяет политику хранения
данных сервиса. API-ключи и тексты переводов не включены в публичный dotfiles.

Без ключа проверяется только интерфейс и обработка запросов на тестовых ответах.
Качество реального перевода подтверждается после подключения вашего API-ключа.
