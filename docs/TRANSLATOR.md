# Переводчик

Запуск: **tr** или **tr текст** в Otter, `tiffany-translator` в терминале.
Окно в стиле калькулятора: исходник и перевод рядом, язык перевода, вставка и
копирование. Ctrl+Enter — перевести, Ctrl+Shift+C — скопировать, Esc — закрыть.
Повторный вызов поднимает существующее окно. Размеры Otter сохранены.
Текст из Otter только заполняет поле: отправка происходит по кнопке «Перевести».

В «Настройках API» выберите сервис и нажмите «Сохранить». У каждого сервиса
свои настройки; переключение не стирает ключи и настройки остальных.

## Gemini

Ключ: [Google AI Studio](https://aistudio.google.com/apikey).
По умолчанию `gemini-3.5-flash-lite`, thinking `low` для уменьшения задержки.
Для моделей 2.5 Flash отключается thinking; для незнакомых моделей дополнительные
параметры не навязываются. В локальном тесте техническая фраза перевелась примерно за 1,4 секунды; время зависит от сервиса и сети.
Запрос проверен с установленным ключом. Доступность и квоты зависят от аккаунта.

Промпт задаёт контекст Linux, реверса, ассемблера и анализа ВПО, просит сохранить
код, адреса, регистры, команды и структуру текста. Перевод нужно сверять с оригиналом.
[Модель](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite),
[thinking](https://ai.google.dev/gemini-api/docs/generate-content/thinking).

## DeepL

Ключ: [DeepL Developers](https://www.deepl.com/en/developers).
Вставьте его в скрытое поле. Endpoint выбирается по ключу: `:fx` — API Free,
остальные — основной API. Укажите модель:

- `latency_optimized` — приоритет скорости, по умолчанию;
- `quality_optimized` — приоритет качества;
- `prefer_quality_optimized` — качество с поддерживаемым для языковой пары вариантом.

Запрос включает технический контекст и сохранение форматирования.
[Контракт API](https://developers.deepl.com/api-reference/translate/request-translation).
Историю, словари и другие данные из вашего аккаунта приложение само не загружает.

## Google Cloud Translation Advanced (v3)

Это отдельный сервис: API-ключ Gemini **не подходит**.
[Авторизация](https://docs.cloud.google.com/translate/docs/authentication).

1. В Google Cloud создайте/выберите проект с биллингом и включите Cloud Translation API.
2. Выдайте сервисному аккаунту роль **Cloud Translation API User**
   (`roles/cloudtranslate.user`), создайте его JSON авторизации.
3. В настройках переводчика укажите **ID проекта**, регион `global`, модель
   `general/nmt`, затем выберите JSON и сохраните.

Выбранный JSON копируется в закрытую папку приложения с правами 0600.
Не добавляйте исходный файл в dotfiles/Git. Если JSON лежит в Downloads,
после успешного сохранения можно удалить исходник — приложение использует копию.
Альтернатива — настроенный локально ADC в
`~/.config/gcloud/application_default_credentials.json` или путь через
`GOOGLE_APPLICATION_CREDENTIALS`; файлу нужны права 0600.

OAuth-токен получается автоматически; вводить/обновлять его вручную не требуется.
Установлена официальная библиотека `google-auth` в отдельное Python-окружение.
Восстановление зависимости: `translate-install-auth`. Системный Python не изменяется.
Поддерживаются JSON сервисного аккаунта и локальный ADC пользователя;
федеративные/внешние JSON в этом приложении не поддерживаются.
По умолчанию переводится обычный текст через NMT. Строка модели допускает
`general/translation-llm` и полный ресурс модели, если они доступны в вашем проекте.
Создание облачного проекта, подключение оплаты и выдача прав выполняются вами.
[REST API](https://docs.cloud.google.com/translate/docs/reference/rest/v3/projects.locations/translateText).

## Консоль

```sh
translate 'The function validates the buffer length.'
translate --to en 'Функция проверяет длину буфера.'
printf '%s' 'memory mapping' | translate
translate --clipboard --copy
translate --setup
translate --ui
```

Консольный интерфейс: `/paste`, `/edit`, `/copy`, `/to ru|en|auto`, `/q`.
Авто: преобладают кириллические буквы → английский, иначе → русский.
Смешанный текст лучше переводить с явно выбранным языком. До 12 000 символов.
Автоматических повторов, смены провайдера или перехода на платный тариф нет.
GUI не зависает во время запроса; при закрытии окна его рабочий процесс завершается.

## Данные и проверки

`~/.config/tiffany-translate/`:

- `config.json` — текущий сервис; `gemini.json`, `deepl.json`, `google.json` — его профили;
- `gemini.key`, `deepl.key` — ключи, права 0600;
- `google-credentials.json` — импортированные закрытые данные Google, права 0600.

Вместо ключей в файлах можно использовать `GEMINI_API_KEY` и `DEEPL_API_KEY`.
История переводов не сохраняется, кэш до 32 ответов только в памяти.
Буфер не наблюдается в фоне; копирование сохраняется после закрытия окна.
Во внешний API уходит введённый текст; условия хранения определяет сервис.
Непубличные тексты и образцы не отправляйте без оценки политики выбранного сервиса.
Ключи, OAuth-токены и переводы не включены в публичный репозиторий.

Контракты трёх сервисов проверяются тестами на подставных ответах.
Реальные DeepL и Google Cloud проверяются после добавления ваших учётных данных.
