# Переводчик Gemini

Запуск: **tr** или **tr текст** в Otter, `tiffany-translator` в терминале.
Окно в стиле калькулятора: исходник и перевод рядом, выбор языка, вставка и
копирование. **Enter** переводит, **Shift+Enter** добавляет строку,
**Ctrl+Shift+C** копирует результат, **Esc** закрывает.
Повторный вызов поднимает существующее окно. Размеры Otter сохранены.
Текст из Otter только заполняет поле: отправка происходит по Enter или кнопке.

В «Настройках API» укажите модель и ключ [Google AI Studio](https://aistudio.google.com/apikey).
Ключ вводится в скрытое поле; пустое поле сохраняет уже настроенный ключ.
По умолчанию `gemini-3.5-flash-lite`, thinking `low` для уменьшения задержки.
Для моделей 2.5 Flash отключается thinking. Время ответа зависит от сервиса и сети:
в локальных тестах небольшие технические фразы переводились примерно за 1–5 секунд.
Квоты и доступность определяются аккаунтом Gemini.

Промпт задаёт контекст Linux, реверса, ассемблера и анализа ВПО, просит сохранять
код, адреса, регистры, команды и структуру текста. Проверяйте перевод по оригиналу.
[Модель](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite),
[thinking](https://ai.google.dev/gemini-api/docs/generate-content/thinking).

## Консоль

```sh
translate 'The function validates the buffer length.'
translate --to en 'Функция проверяет длину буфера.'
printf '%s' 'memory mapping' | translate
translate --clipboard --copy
translate --setup
translate --ui
```

Консольный интерфейс: `/paste`, `/edit`, `/copy`, `/to ru|en|auto`, `/q`.
Авто: преобладают кириллические буквы → английский, иначе → русский.
Для смешанного текста лучше явно выбрать язык. До 12 000 символов за запрос.
Автоматических повторов и переключений на другие сервисы нет.
Окно остаётся отзывчивым во время запроса; при закрытии рабочий процесс завершается.

## Локальные данные

`~/.config/tiffany-translate/config.json` и `gemini.json` — модель и сервис;
`gemini.key` — ключ с правами 0600. Можно использовать `GEMINI_API_KEY`.
История переводов не записывается. Кэш до 32 ответов хранится только в памяти.
Буфер не наблюдается в фоне. Скопированный ответ остаётся после закрытия окна.
Ключи и тексты переводов не включены в публичный репозиторий.
Внешний API получает только явно отправленный текст; хранение определяется условиями Gemini.
