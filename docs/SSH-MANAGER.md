# SSH-менеджер

Установлен [lazyssh](https://github.com/Adembc/lazyssh), Go TUI поверх обычного
OpenSSH. Запуск: `lazyssh` в терминале или **ssh** в Otter. Открывается большой
терминал; размеры самого Otter сохранены.

- ↑/↓ или j/k — выбрать сервер; Enter — подключиться.
- / — поиск; p — закрепить; s — сортировать.
- a — добавить; e — изменить; Ctrl+S — сохранить форму, Esc — отменить.
- c — скопировать команду; g — вручную проверить доступность; q — выйти (из поиска сначала Esc).
- f — проброс порта; x — остановить проброс.

Список читается из `~/.ssh/config`: используются ваши алиасы, ключи,
ssh-agent и ProxyJump. Перед редактированием конфигурации приложение создаёт
резервные копии рядом с ней. Метаданные — в `~/.lazyssh`.
Программа не включает SSH-сервер и не открывает порты сама по себе.
Проверка ключей серверов остаётся за OpenSSH; параметры безопасности не ослаблены.
В терминал SSH передаётся `TERM=xterm-256color`.

Установка без root: `lazyssh-install` (нужны git и go).
Исходники закреплены на коммите `07cb2abb1abf65d4036a7574c2b33a1808d5614f`,
зависимости проверяются через Go modules. Бинарник:
`~/.local/libexec/lazyssh`; оболочки в `~/.local/bin`.
Автоустановка dotfiles с пакетами также собирает lazyssh при наличии Go.
Удаление бинарника не удаляет SSH-конфиг и ключи.
