# Исправления обзора 05.11.2026

Пакеты пока не обновляются; энергопрофили не меняются, новые прикладные программы не устанавливаются.

Пользовательская часть:
- NVIDIA sleep checker принимает актуальные версии ветки 580 и по-прежнему проверяет соответствие модуля ядру и включённые VRAM-службы.
- План Proton включает актуальные Linux RE/English, календарные заметки и согласованную копию базы таймера (SQLite backup API).
- Из архива исключены повторно собираемые target, recovery-дубликаты, Syncthing .stversions и обои dotfiles (хранятся в Git). Исходные файлы не удалялись.
- Ошибка размера возвращает EX_CONFIG=78; systemd её не повторяет как временную сетевую ошибку.
- Статусы полной копии и последнего успешного KeePass показаны отдельно.
- Установщик включает audio-preset и portable-status. Последняя команда показывает переносимые ImHex/Syncthing/Ghidra отдельно от обновлений pacman/yay.
- Календарь, погода, Deck, уведомления и калькулятор используют согласованные основные цвета/шрифт интерфейса; моноширинные поля калькулятора сохранены. Геометрия Otter не менялась.
- Otter: health — существующий отчёт обслуживания, learn — Yazi в learning/linux-re.
- Меню ВМ проверяет debian_RE перед запуском: isolated без forward, отсутствие shared filesystem/hostdev, наличие базового снимка. Это не гарантия защиты от аппаратных атак и не применяется к прямому запуску через virsh/virt-manager.

Системная часть применяется командой:

```sh
sudo python ~/dotfiles/scripts/maintenance/finish-system-review.py --apply
```

Скрипт сохраняет изменяемые файлы в /var/backups/system-review-*, добавляет только домашние правила Syncthing в собственную nft input chain (без reload всей сети), удаляет игнорируемый параметр аудио, завершает застрявший системный dirmngr и ограничивает будущие зависания (25% CPU, максимум 20 минут на экземпляр), запускает штатную проверку ключей, выборочно чистит pacman и три orphan debug-пакета, собирает root-отчёт.

При необходимости отката файлы из каталога резервной копии можно вернуть на исходные пути; исходный live input chain сохранён как firewall-before.json. Удалённые кэши не восстанавливаются. Пакеты удаления перечислены явно, рекурсивное удаление зависимостей не используется.

Tor используется активными соединениями и оставлен. Bluetooth/Qwen не отключаются без подтверждённой ненужности. Старые настройки KVM не меняются без теста зависимых ВМ. BIOS/микрокод/пакет wireless-regdb и полное обновление относятся к заключительному этапу; GDS не считается исправленной. При смене BIOS нужна отдельная проверка точной модели и питания.

Общие резервные копии пользовательских настроек до изменений: ~/.local/state/system-review-fixes/20261105-091840.

UID и проверенному manifest облачной версии.

Последующая DNS-проба GnuPG: встроенный резолвер возвращает DNS Timeout,
standard-resolver + no-use-tor успешно получает публичный WKD-ключ. Это проверено
во временных GNUPGHOME без изменения личных ключей. Для системного pacman:
`sudo python ~/dotfiles/scripts/maintenance/finish-keyring-network.py --apply`.
Скрипт сохраняет прежний конфиг, проверяет реальную загрузку WKD и при отказе
возвращает прежние настройки. Личная ~/.gnupg, Tor и настройки Throne не меняются.
