## Proton: предупреждения и хранилище ключей

proton-quota.timer включён: в 18:30 и после запуска пользовательского менеджера
с задержкой 5 минут, плюс случайная задержка до 2 минут. Проверяется размер
/my-files относительно выбранного приватного бюджета. Предупреждения на 80%
и 90%, не чаще раза в сутки для одного уровня; повышение уровня уведомляет
сразу. Файлы не загружаются и не удаляются. Параллельные запросы защищены flock.

После разблокировки Default Keyring реальный запрос прошёл:
803.3 МиБ / 1907.3 МиБ = 42.1%. Доступ к облаку зависит от разблокированного
OS keychain; пароль не переносился и не сохранялся в конфиги. Если после
следующего входа keyring снова заблокирован, проверка уведомит, а страница
покажет кнопку «Разблокировать ключи». Она открывает стандартное окно
Secret Service, не собственную форму ввода пароля. Повторный вход Proton
может понадобиться, если авторизация действительно истечёт.

## Остался root-шаг

```bash
sudo python ~/dotfiles/scripts/maintenance/finish-desktop-enhancements.py --apply
```

Он установит extra/udiskie и extra/bpftrace, затем удалит только три выбранных
пакета через pacman -R без рекурсивной очистки зависимостей. При работающем
v2ray/crond остановится до изменений. Сохранит cron и список пакетов в
root-only /var/backups/desktop-enhancements-ДАТА-ВРЕМЯ.

Установит read-only workstation-health-status.service/timer: SMART/Btrfs
после загрузки и раз в 6 часов. В опубликованный локальный JSON не попадают
серийные номера/ключи; файл доступен только root и группе eto. Включены
ProtectSystem, ProtectHome, PrivateNetwork и NoNewPrivileges. Сам сборщик
не запускает тесты диска или scrub.

Отдельно скрипт выполнит первый fstrim.service, проверив точную команду
fstrim --verbose /, затем получит снимок здоровья и проверит bpftrace
самозавершающейся BEGIN-программой. Установленный udiskie запустится в
пользовательском сеансе; automount выключен, управление накопителями через
трей. Конфигурация ~/.config/udiskie/config.yml.

Root-шаг пока не выполнен; SMART/scrub на странице честно показывают
отсутствие свежего снимка. Перезагрузку и сон скрипт не выполняет.
