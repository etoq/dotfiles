# EasyEffects: Fifine и G435

Настроено 2026-11-04 для EasyEffects 8.3.1.

- Системный микрофон остаётся физическим устройством. EasyEffects следует его выбору (`useDefaultInputDevice=true`).
- Fifine: автопресет `12(1)`, захват приложений проходит через EasyEffects Source.
- G435: исключён из автоматической обработки, автопресет `Microphone Direct` с пустой цепочкой. Вновь открытый захват идёт напрямую с G435.
- Встроенный микрофон также исключён; на его порты назначен пустой пресет.
- Громкость микрофонов, выходная цепочка и настройки Wispr не менялись.

При смене микрофона закончить текущую диктовку, выбрать физический микрофон и начать следующую. Если в приложении явно закреплён другой микрофон, выбрать нужное устройство и в нём.

## Fifine: более мягкое начало фразы

- RNNoise VAD: 80 → 70%.
- Gate threshold: −30 → −33 dB.
- Attack 1 ms, reactivity 35 ms и фактический lookahead 20 ms сохранены.
- Цепочка RNNoise → Gate → EQ → Compressor → Limiter сохранена.

Это небольшое снижение порога открытия, а не увеличение аппаратного усиления. Проверка маршрутов не подтверждает качество речи: нужно оценить несколько тихо начатых фраз и шум клавиатуры в обычной обстановке.

## Файлы

Рабочие пресеты: `~/.local/share/easyeffects/input/`.
Автопрофили: `~/.local/share/easyeffects/autoload/input/`.
Настройки: `~/.config/easyeffects/db/`.
Копии пресетов/профилей и фрагмент маршрутизации: `~/dotfiles/configs/easyeffects/`.

Резервная копия до изменений: `~/.local/state/easyeffects-backups/20261104-133623/`.

При восстановлении или переносе сначала остановить EasyEffects, затем копировать файлы, затем запустить: файловый наблюдатель EasyEffects 8.3.1 может упасть, прочитав ещё не дописанный JSON.

## Проверено

Тестовый захват в `/dev/null`, без сохранения записи:

- G435 → `Microphone Direct` → физический G435.
- Fifine → `12(1)` → `easyeffects_source`.
- После проверки исходный Fifine восстановлен, служба EasyEffects запущена.

## Два режима G435 и небольшая правка Fifine

2026-11-04: подъём Fifine на 120 Гц уменьшен с +2 до +1 dB в обоих каналах. Другие параметры входного пресета сохранены.

- `12-output` — прежний музыкальный пресет: бас +3 dB, crossfeed, лимитер.
- `G435 - Films and Courses` — бас +1 dB, без crossfeed; компрессор 2:1, threshold −24 dB, attack 20 ms, release 200 ms, makeup +2 dB, knee −6 dB; лимитер −1 dB. Это мягкое уменьшение динамического диапазона, не автоматическое выделение диалога.

Переключение через Output presets в EasyEffects или:

```sh
easyeffects -l '12-output'
easyeffects -l 'G435 - Films and Courses'
```

Пресеты для воспроизведения не меняют входной микрофонный пресет. Сравнивать на знакомом материале при сопоставимой громкости; качество звучания по конфигурации не подтверждено.

Резервная копия до этой правки: `~/.local/state/easyeffects-backups/20261104-135703/`.
