# Одностраничные справочники

- **Win+F1** — существующая справка AwesomeWM.
- **Win+F2** — Neovim: основные режимы, сохранение, Telescope, буферы/вкладки,
  дерево файлов, поиск/замена, Git, LSP, ошибки, запуск, DAP и HEX. Расширено до
  12 разделов; отдельное окно 1840×960, одна страница при 1920×1080.
- **Win+F3** — Fish и Kitty: реальные алиасы, fzf, навигация, Git, пакеты,
  Thinkfan, буфер обмена, вкладки и история вывода терминала.
- **Win+F4** — Yazi: перемещение, поиск, выделение, файлы, пути, вкладки и preview.
- **Win+F5** — Otter: команды, сгруппированные по назначению.
- **Win+F6** — GDB/pwndbg: запуск, точки, шаги, память, регистры и стек.
- **Win+F7** — RE CLI: file, строки, ELF, objdump, radare2 и свои анализаторы.
- **Win+F8** — Ghidra: проверенный профиль Linux с основными сочетаниями IDA.
- **Win+F9** — свои скрипты: проверки, файлы, ВМ, резервирование и удобство.

Окна используют тот же нативный виджет, что Win+F1, в Black Tiffany. Каждая
подборка — одна страница при 1920×1080; закрывается Esc, любой другой клавишей
или щелчком, как штатная справка. Сочетания Neovim/Fish/Kitty/Yazi не переназначены.
В Neovim Leader — пробел. `Ctrl+A` в твоём конфиге копирует весь файл, а `Ctrl+L`
закрывает остальные буферы — эти особенности отражены в справке.
Подробное руководство: `docs/NEOVIM-GUIDE.md`; внутри редактора **Пробел ug**
или `:NvimGuide`. При меньшем разрешении нативный виджет ограничивает окно
доступным местом и может разбить справку на страницы.

Источник: `configs/awesome/cheatsheets.lua`, бинды — `configs/awesome/rc.lua`.
Подборки составлены по `configs/nvim/`, `configs/fish/config.fish`, установленным
fzf-биндам Fish, `configs/kitty/kitty.conf` и `configs/yazi/keymap.toml`.
Это краткие справочники, не полный экспорт. F5 каждый раз читает команды из
живого конфига Otter, F9 скрывает отсутствующие скрипты. Их данные формирует
`scripts/local-bin/cheat-data`, который ничего из перечисленного не запускает.

## Ghidra

Проверен текущий CodeBrowser из `ghidra_12.2_DEV`, а не стандартный список из
интернета. В старом профиле часть сочетаний использовала Meta (Win), который
перехватывает Awesome. Профиль `configs/ghidra/ida-linux.kbxml` переводит их на
Ctrl и настраивает основные действия по образцу IDA: C/U, P/Alt+P, N, Y, X,
F5, D, A, O, Space. Это не полная копия IDA: Ctrl+F6 возвращает предыдущую
активную панель, F5 открывает декомпилятор, Space переключает Listing/Function Graph.
Поиск текста Alt+T, повтор Alt+F3; Ctrl+F3/Ctrl+Shift+F3 зарезервированы Ghidra
для перехода между окнами. Source Code Lookup перенесён на Ctrl+Alt+F3.

Применено только к категории Key Bindings пользовательского шаблона CodeBrowser;
тема, плагины, окна и проекты сохранены. Резервная копия исходного файла:
`~/.local/state/ghidra-keybindings-backup/`. Для повторного применения при
закрытой Ghidra:

```sh
python ~/dotfiles/scripts/maintenance/apply-ghidra-keybindings.py --apply
```

Если другой инструмент/сохранённый проект использует отдельный профиль:
Edit → Tool Options → Key Bindings → Import →
`~/dotfiles/configs/ghidra/ida-linux.kbxml`, затем сохранить настройки инструмента.
Все 99 записей проверены в отдельном GUI-экземпляре установленной Ghidra с
временным проектом и статическим импортом `/bin/true`. Проверена регистрация и
загрузка клавиш; это не ручное выполнение каждого действия над рабочим проектом.
Некоторые одинаковые клавиши штатно разделяются по контексту активной панели.
