# Погода

Win+Shift+W открывает компактную карточку, повторное нажатие закрывает её.
При первом открытии выберите город: введите название, нажмите Enter и выберите
подходящий результат с областью и страной. Нажатие на название города открывает
поиск и восемь последних выбранных городов. Esc возвращает из поиска или закрывает карточку.

Показаны температура, ощущаемая температура, ветер в м/с, текущие осадки в мм,
шесть ближайших часов и три дня. Проценты означают вероятность осадков;
суточные температуры показаны в порядке минимум / максимум.
Часы прогноза указаны по местному времени выбранного города.

Источник: Open-Meteo Best Match (https://open-meteo.com/en/docs), координаты из
https://open-meteo.com/en/docs/geocoding-api. Текущие условия основаны на моделях,
не на датчике рядом с пользователем; точность зависит от местоположения и условий.
Запрос при открытии, вручную кнопкой ↻ и каждые 15 минут, пока окно открыто.
Время получения данных показано в часовом поясе ноутбука.
Без сети используется последний прогноз с явной отметкой. Приложение не работает
в фоне после закрытия, не требует регистрации или API-ключа.

Город и кэш: `${XDG_STATE_HOME:-~/.local/state}/tiffany-weather/`.
Зависимости Arch: python, python-gobject, gtk3. Запуск: `~/.local/bin/tiffany-weather`.
