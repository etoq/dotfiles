# Black Tiffany: оформление и быстрые действия

- Win+Q — буфер: поиск, предпросмотр, Enter копирует, ☆ закрепляет/убирает выбранный текст. Избранное хранится приватно в ~/.local/share/tiffany-picker/pins.json. Карточка читает исходные записи Greenclip, а не однострочный вывод меню. Переносы, табуляция, отступы, пустые строки и неразрывные пробелы сохраняются при выборе. Обрезание начальных/конечных пробелов отключено. Ранее обрезанные пробелы в старых записях восстановить невозможно; внутренние переносы читаются из сохранённой истории.
- Win+Ctrl+Tab — окна: рабочий стол, приложение, заголовок и отметка свёрнутого. Enter раскрывает окно и переключает на его стол. Win+Tab остался прежним.
- Win+Ctrl+N — история уведомлений. Enter копирует текст выбранного уведомления. Esc закрывает карточки, ↑/↓ выбирают запись.
- Dunst: история 50 сообщений; критические остаются до закрытия, дубликаты объединяются.
- Yazi: `, p` копирует путь, `, s` — SHA-256, `, h` открывает файл в ImHex, `, d` — в DIE, `, g` открывает Ghidra и кладёт путь в буфер для импорта через I. Путь не превращается в аргумент запуска проекта Ghidra. В Downloads сортировка по свежести и размеры, в остальных папках — по имени.
- Kitty: Ctrl+Shift+↑/↓ — предыдущая/следующая команда; Ctrl+Shift+G — вывод последней команды; Ctrl+Shift+Y — копирование вывода. Эти действия требуют shell integration Kitty; для SSH она должна работать и на удалённой стороне. Масштаб и прозрачность не менялись.
- Otter: короткие описания, старые префиксы сохранены; cal теперь обозначает новый календарь. Геометрия и число вариантов не менялись. Короткие точные префиксы расположены перед своими расширениями (например, cal перед calc); алгоритм сопоставления остаётся штатным Otter 0.8.2.
- Панель: звук нейтральный, CPU оранжевый от 75%, красный от 90%. Тени смягчены, системные GTK-диалоги согласованы по основному шрифту с карточками. Qt-программы с собственными темами могут сохранять своё оформление.

Резервная копия конфигураций до изменений: ~/.local/state/desktop-polish-backups/before-*.tar.gz.
Содержимое буфера, заголовки открытых окон и избранное не публикуются в Git.

При применении теней Picom завершился на SIGHUP; композитор был запущен заново. Значение background_opacity Kitty осталось 0.7. Для этой сборки Picom SIGHUP больше не используется.
