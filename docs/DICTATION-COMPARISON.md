# Бесплатное сравнение диктовки · 28 октября 2026

Подготовлены только локальные движки. Ключи API, облачная подписка и аккаунт не
нужны. Wispr оставлен для отдельного ручного сравнения. OpenWhispr не установлен.

## Что установлено

| Вариант | Модель | Вычисления |
|---|---|---|
| Handy 0.9.8 | Parakeet TDT 0.6B V3, ONNX INT8 | CPU |
| Handy 0.9.8 | GigaAM v3 e2e CTC, ONNX INT8 | CPU |
| Handy 0.9.8 | Whisper Medium GGUF Q5_K_M | CPU |
| hyprwhspr | Whisper Medium GGML Q5_0 через pywhispercpp 1.5.1 | CPU wheel |
| whisper.cpp, отдельная сборка | Whisper Large v3 Turbo Q5_0 | Vulkan или CPU |
| whisper.cpp, та же сборка | coriollon Russian Code-Switching Turbo Q5_0 | Vulkan или CPU |
| whisper.cpp, та же сборка | Уже установленная Whisper Medium Q5_0 | Vulkan |

Handy взят из официального AppImage; проверен SHA-256 релиза. Каталог моделей
проверен по исходникам именно тега v0.9.8. Сервер старых ONNX-архивов Handy
вернул HTTP 403, поэтому те же экспорты загружены по закреплённым ревизиям
`istupakov/parakeet-tdt-0.6b-v3-onnx` и `istupakov/gigaam-v3-onnx`, рекомендованным
библиотекой transcribe-rs. Имена файлов сверены с transcribe-rs 0.3.8 из Cargo.lock.
Проверены SHA-256 больших файлов и Git blob hashes небольших vocabulary-файлов.

Точные URL, ревизии и хеши: `configs/dictation-compare/install.json`.
Пакеты Python зафиксированы в `requirements.txt`, source hyprwhspr — в manifest.
Установка пользовательская, не AUR: обычный `upd` не обновляет эти две копии.
Автозапуск обоих выключен. NVIDIA, сеть, VM и политика сна не менялись.

Ранее скачанные GGUF Parakeet/GigaAM удалены после проверки ONNX. Они заметно
медленнее на этом CPU и дублировали варианты. Оставлены только модели таблицы.
Загрузка моделей и сами приложения заняли примерно 2.4 ГиБ, плюс архив Handy и
отдельное Python-окружение. Это размер на диске, не постоянное потребление RAM.

## Команды и бинды

| Команда Otter / клавиши | Действие |
|---|---|
| `vc` | Окно сравнения на одной аудиозаписи |
| `ha` | Handy: модели и настройки |
| Win+Alt+S | Handy: начать / остановить диктовку |
| Win+Ctrl+Alt+S | Medium Vulkan: начать / остановить живую диктовку |
| Win+Ctrl+Alt+Esc | Отменить запись или распознавание Medium Vulkan |
| `wh` | То же переключение записи Medium Vulkan |

Сначала начинать один вариант и заканчивать его запись, затем пробовать другой.
Для Handy выбрана Parakeet V3; GigaAM/Whisper переключаются в его разделе Models.
Handy получает терминологию из общего `terms.txt`. Оверлей отключён, чтобы не
перехватывать фокус, вставка в терминале — Ctrl+Shift+V, в других окнах — Ctrl+V.
Enter автоматически не нажимается. Автосохранение записей Handy выключено.

Живая диктовка использует `dictation-live.service`, запускаемую по бинду. На вход
она не включена. Idle — около 10 МиБ RAM, микрофон выключен, модель не держится
в GPU. Первое нажатие начинает pw-record PCM16/mono/16kHz, второе останавливает
запись и запускает **один** проход Medium Q5_0/Vulkan/beam_size=5/Flash Attention.
Это те же веса, подсказка и настройки, что у удачного batch-профиля Medium GPU.
Двойной проход остаётся только в сравнении `vc`.

Запись ограничена 120 секундами. Слишком короткая/очень тихая запись отклоняется
по RMS; это не полноценный VAD. На блокировке запись/распознавание отменяются.
WAV и временный текст находятся в приватном runtime-каталоге и удаляются после
завершения/отмены. В `~/.local/state/dictation-live/engine.log` остаётся только
технический журнал, без расшифровки. После вставки текст остаётся в буфере.

Окно запоминается на начале записи. Если оно осталось активным, используется
Ctrl+Shift+V для терминала и Ctrl+V для обычных приложений. Если окно изменилось,
текст только копируется и показывается уведомление. Enter не нажимается.
Clipboard публикуется явно как UTF8_STRING, чтобы терминал не пытался вставить
старое изображение. Наложения поверх приложений и LLM-переписывания нет.

Статус, отмена и остановка службы:

```sh
dictation-live status
dictation-live cancel
systemctl --user stop dictation-live.service
```

Прежний hyprwhspr CPU сохранён для сравнения, его idle-служба остановлена.
Ручной вызов старого режима: `dictation-control hypr-legacy-toggle`.
Handy закрывается через Quit в трее.

### Проверка живой вставки

1. Открыть поле ввода Codex, нажать Win+Ctrl+Alt+S и дождаться уведомления записи.
2. Произнести фразу про ELF/Ghidra/ptrace и снова нажать этот бинд.
3. Дождаться распознавания. Проверить текст в поле; отправка остаётся ручной.
4. Повторить в черновике AyuGram: обычная фраза и фраза с техническими словами.
5. Проверить смену окна во время распознавания: результат должен остаться
   в буфере, без автоматической вставки. Затем проверить отмену отдельным биндом.

Проверены one-pass GPU (~12.4 с на прежнем WAV), старт микрофона и отмена без
распознавания (1 секунда, временная запись удалена), IPC idle/recording/idle,
реальные UTF8-вставки в изолированных GTK X11-окнах с WM_CLASS kitty/AyuGram,
терминальный и обычный paste, отсутствие Enter и защита при смене окна.
Это проверки компонентов; ручная диктовка в настоящих Codex/AyuGram ожидает
пользовательской проверки. Бинды не требуют root или доступа к /dev/input.

## Как сравнить

1. Открыть `vc`, выбрать фразу или вписать свою.
2. Нажать «Начать запись», прочитать фразу, нажать «Остановить запись».
3. Выбрать набор моделей и нажать «Сравнить выбранные». Движки считают
   последовательно на **одном WAV**. По умолчанию выбраны Medium и две Turbo на Vulkan.
4. Повторить с 5–8 фразами: обычный русский, термины RE, смешанная речь, числа.
5. Отдельно проверить живую вставку в Codex и Telegram обоими биндами.

Кнопка «Открыть WAV» позволяет повторить тест уже сохранённой записи. Если рядом
есть `reference.txt`, он подставится автоматически. Результаты такого повтора
сохраняются в новой папке; `audio-source.json` содержит путь и SHA-256 исходника.

В окне выводятся текст, WER, число точно переданных терминов, загрузка модели
и время первого/второго распознавания. WER меньше — лучше; регистр/пунктуация не
учитываются. Счётчик терминов не оценивает смысл. Ошибки движка сохраняются,
а не скрываются за успешным результатом других вариантов.
Если произнести фразу иначе, чем написано в эталоне, WER посчитает и эти
расхождения ошибками. Это расстояние до выбранного текста, не экспертная оценка.

Время распознавания не равно задержке бинда до вставки. Холодная загрузка указана
отдельно. Во втором прогоне модель уже находится в памяти. Форматы и квантование
различаются, а настройки домена тоже не идентичны: это сравнение готовых
конфигураций, не чистый эксперимент «одна модель, разные оболочки».
У Handy в batch-пути остаётся его обработка custom words; hypr batch использует
RE initial_prompt, но не живые word_overrides. LLM-переписывания нигде нет.

WAV, reference.txt, results.json, CSV и журналы сохраняются локально:
`~/.local/state/dictation-compare/runs/`. Они не загружаются в Git или облако.
WAV остаётся для воспроизводимого сравнения; папку теста можно удалить после.
Запись ограничена 60 секундами. Закрытие окна останавливает запись и вычисление.

Из терминала с уже готовым WAV PCM16/16000/mono:

```sh
dictation-compare run /path/sample.wav --reference /path/expected.txt
```

## Что проверено

- Официальный релиз запускается, реальные модели загружаются в Handy.
- hyprwhspr запускается, отвечает Idle по IPC, не требует чтения клавиатуры.
- Штатный WAV transcribe-rs «Проверка связи»: GigaAM и обе Whisper вернули фразу;
  Parakeet на секундном клипе дал пустой ответ. На удлинённом русском клипе
  Parakeet распознаёт русский, но ошибается в словах. Это наблюдение на тестовых
  образцах, не итоговый рейтинг на голосе пользователя.
- На i7-6700HQ Whisper Medium на CPU имеет существенную задержку даже для
  короткой записи; оставлен именно как вариант сравнения точности.
- Интерфейс сравнения проверен в отдельном X11-экране без открытия микрофона.
- Модульные проверки: WER, термины, WAV, четыре локальные команды, экспорт,
  отмена и проверка хеша. Пользовательские записи проверены на втором этапе ниже.

Контрольный прогон: `~/.local/state/dictation-compare/verification/results.json`.
Он использовал открытый sample из transcribe-rs 0.3.8; исходник проверен по
checksum Cargo.lock. Синтетическая речь espeak использовалась только для smoke
проверки, её ошибки нельзя переносить на качество распознавания живой речи.

## Повторная установка

После развёртывания dotfiles:

```sh
dictation-compare-install
systemctl --user daemon-reload
```

Скрипт проверяет скачанные хеши, не использует root, не включает службы на вход,
не запускает микрофон. Зависимости GTK/WebKit/gtk-layer-shell/PortAudio/PipeWire,
xdotool и xclip должны быть установлены в системе. Текущие параметры Handy
сохранены в `settings_store.pre-comparison.json` перед первоначальной настройкой.
При обновлении версий нужен отдельный пересмотр manifest и форматов моделей.

## Turbo и ускорение · второй этап

```sh
dictation-turbo-install
```

Установщик требует cmake, Ninja, C++17, Vulkan headers/loader и glslc. Заголовки
SPIR-V устанавливаются только в пользовательский build-deps. Драйвер NVIDIA,
CUDA, системные пакеты и автозапуск не изменяются. Сборка whisper.cpp и заголовки
закреплены по Git revision; веса и файлы преобразования — по ревизиям/хешам в
`configs/dictation-compare/turbo.json`. Скрипт преобразования использует NumPy
из уже установленного окружения hyprwhspr: PyTorch не нужен.

Техническая модель распространяется в Safetensors F32; преобразуем её в GGML
F16 по схеме официального convert-h5-to-ggml.py, затем quantize Q5_0. Временные
F32/F16-веса удаляются после проверки итогового хеша. Остаются два файла Q5_0,
примерно 548 МиБ каждый. `--keep-source` сохраняет Safetensors для исследования.

Обе Turbo используют один runtime, русский язык, одну RE-подсказку, beam search
beam_size=5 без температурных повторов, четыре CPU-потока. Flash Attention
включён. Одна загрузка модели и два распознавания WAV; измерения загрузки и
распознавания разделены. Время Vulkan включает передачу данных и вычисления,
а не только GPU kernel. `texts` в JSON содержит оба результата, UI/WER — второй.

Специализированная модель — экспериментальный кандидат. Её автор использовал
синтетическую речь и ограниченный список технических терминов; улучшение на
терминах реверса не гарантируется. Проверять на своём голосе и разных фразах.
Две Turbo и Medium Vulkan доступны в batch-сравнении. Для живой проверки
подключён Medium Vulkan; Handy остаётся отдельным вариантом на Win+Alt+S.

### Результат на двух сохранённых записях пользователя

Фразы: ELF/Ghidra/ptrace (7.29 с) и shellcode/UPX/YARA (5.29 с).
Одинаковый beam_size=5, Flash Attention, одна RE-подсказка и runtime.
Время ниже — второе распознавание, после загрузки/первого прохода.

| Вариант Vulkan | WER, первая / вторая | Термины, первая / вторая | Время, первая / вторая |
|---|---|---|---|
| Medium Q5_0 | 0% / 22.2% | 3/3 / 3/3 | 11.42 / 12.42 с |
| Обычная Turbo Q5_0 | 40% / 44.4% | 1/3 / 2/3 | 16.65 / 17.11 с |
| RU+EN Code-Switching Turbo Q5_0 | 50% / 66.7% | 0/3 / 1/3 | 16.84 / 17.07 с |

На этих записях Medium Vulkan оказался быстрее и точнее обеих Turbo.
Исходный hyprwhspr Medium CPU на первой записи дал 0% WER за ~30 с.
Первый GPU-проход Medium занял 13.38 / 12.52 с, загрузка ~0.5 с.
Это не измерение полной задержки «остановил микрофон → текст вставился».
На других голосах, фразах и оборудовании порядок может измениться.

Для отдельной проверки ускорения обычная Turbo в быстром greedy-режиме
на первой записи считала ~47 с на CPU против ~18 с на Vulkan. В GPU-журнале
подтверждён Vulkan0/Quadro M1000M; карта не поддерживает FP16 compute в этом
backend. При недоступности GPU профиль теперь завершается ошибкой вместо
молчаливого вычисления на CPU под названием Vulkan.

Полные локальные результаты, оба текста каждого прохода, SHA-256 аудио и логи:
`~/.local/state/dictation-compare/turbo-verification/elf-beam/` и
`~/.local/state/dictation-compare/turbo-verification/shellcode-beam/`.
Оригинальные записи и полные результаты не включены в Git.

## OpenWhispr: что есть дополнительно

Пока не установлен. По README и документации доступны:

- Диктовка с переводом, исправление/переписывание выделенного текста.
- Ассистент по отдельному бинду; можно передавать выделение, опционально снимок.
- Заметки, папки, поиск, импорт аудио/видео и пакетная расшифровка.
- Запись встреч, разделение говорящих, интеграции с календарём.
- Локальные LLM и облачные провайдеры по выбору; локальная обработка требует RAM
  и добавляет время после ASR, особенно на этом ноутбуке.
- Синхронизация, общий доступ, API/MCP и командные функции.

**Не всё это обещано бесплатно.** Тарифная страница подтверждает безлимитную
локальную диктовку бесплатно. У Free ограничены облачные слова и часы встреч;
agent mode, синхронизация, API/MCP перечислены в Pro. Собственный ключ API тоже
не означает бесплатность провайдера. README широко описывает локальные AI-функции,
но доступность конкретной функции в готовом бесплатном релизе надо проверить
отдельно. Поэтому OpenWhispr не скачивался без решения пользователя.
