# Ghidra: Linux RE / CTF / malware analysis

Запуск: `ghi` в Otter или `reverse-ghidra` в терминале. Интерфейс английский.

## Рабочее место

- Black Tiffany, меню и элементы интерфейса 130% через FlatLaf. Масштаб Java 100%, чтобы избежать двойного увеличения.
- Listing и Decompiler: JetBrainsMono Nerd Font 20 вместо 15, остальные моноширинные поля 16 вместо 12. Размер округлён до целого пункта.
- Слева вкладки Functions / Data Types / Symbol Tree / Program Trees. В Functions видны имя и адрес; сигнатура доступна в декомпиляторе.
- В центре ассемблер, справа C; декомпилятору отдано немного больше места.
- Снизу вкладки Defined Strings / Bookmarks / Console. Остальные панели доступны через Window.
- Приведения типов и номера строк включены. Удаление недостижимого кода отключено: подозрительные ветви остаются видны, если декомпилятор их восстановил. Это не гарантирует восстановление всего обфусцированного кода.
- Кэш декомпилятора 30 функций для возврата между недавно открытыми функциями.
- Ошибки красные, специальные токены янтарные, внешние функции синие, выделения Tiffany.

## Привычные клавиши

Сохранён существующий профиль из 99 назначений, похожий на IDA. Он адаптирован к Ghidra, полного совпадения с IDA нет. Некоторые клавиши зависят от активной панели.

| Клавиша | Действие |
| --- | --- |
| N | Переименовать символ / функцию / переменную |
| X | Перекрёстные ссылки |
| C | Дизассемблировать |
| P | Создать функцию |
| Alt+P | Редактировать функцию / сигнатуру |
| U | Снять разметку кода/данных, исходные байты сохраняются |
| A | Переключение char / string / Unicode |
| O | Создать указатель |
| Space | Listing ↔ Function Graph |
| Alt+T | Поиск текста |
| Shift+H | Показ числа в hex |
| Alt+M | Добавить закладку |
| Ctrl+S | Сохранить |
| Ctrl+Z / Ctrl+Shift+Z | Отменить / повторить |

Памятка Ghidra также доступна через Win+F7.

## Короткий маршрут анализа ELF

1. Import File, проверить архитектуру и формат; запуск Auto Analyze выбирать для конкретного файла.
2. Посмотреть Memory Map, импорты и Defined Strings; переходить по XREF к использованию интересующих строк.
3. Найти entry / main, переименовывать функции и переменные по доказанному назначению.
4. Сверять C с Listing: типы, signed/unsigned, размеры операндов, аргументы вызовов и переходы.
5. Сохранять выводы комментариями и закладками. Подозрение и установленное поведение отмечать отдельно.

Профиль меняет интерфейс и настройки инструмента; существующие программы и результаты анализа не переанализирует.

## Повторное применение и откат

Закрыть Ghidra, затем:

```sh
python ~/dotfiles/scripts/maintenance/apply-ghidra-profile.py --apply
python ~/dotfiles/scripts/maintenance/apply-ghidra-keybindings.py --apply
```

До изменения инструмента создаётся копия `_code_browser.tcd` в `~/.local/state/ghidra-profile-backups/<дата-время>/`.
Для отката закрыть Ghidra и скопировать нужную резервную копию поверх
`~/.config/ghidra/ghidra_12.2_DEV/tools/_code_browser.tcd`.

До первоначального оформления сохранены также `reverse-ghidra` и `BlackTiffany.theme` в каталоге `20261030-090306`.

Масштаб FlatLaf: https://www.formdev.com/flatlaf/system-properties/
