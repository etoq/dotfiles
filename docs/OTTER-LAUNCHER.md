# Otter · Black Tiffany

`Win+D` открывает Otter. Пустой ввод запускает меню приложений, обычный
текст ищется в Google. `?` показывает список, Tab дополняет выбранную команду.

Команды расположены по задачам: ежедневное → веб → разработка → RE/CTF →
виртуальные машины → мониторинг → сеть → таймеры и питание.
Порядок одинаковый в подсказках и списке `?`.

Изменения 2026-10-16:

- `ds` запускает установленный Discord, `pai` открывает https://chatgpt.com/.
- `note` каждый раз создаёт отдельный Markdown в `~/notes/quick/` и открывает
  именно этот файл в nvim. Дата и случайный суффикс исключают перезапись.
- Убраны `gg`, `cai`, `br`, `tem`, `temp`, `tg`, `wtr` и устаревший `nht`.
- `fo`, `yz`, `rm`, `kill`, календарь, таймеры и инструменты CTF сохранены.

## Скрытый поиск

Upstream Otter 0.7.3 не поддерживает скрытые модули. Локальная сборка
`0.7.3+tiffany.1` добавляет необязательный `hidden = true`: модуль остаётся
доступен для выполнения, но исключается из подсказок и списка `?`.
Поиск использует служебный `__search`; команды `gg` больше нет.

Готовый бинарник находится в `scripts/local-bin/otter-launcher` и ставится
обычным `install.sh` вместе с `otter-new-note`. Системный пакет не заменялся.
При обновлении локального бинарника следует сохранить поддержку `hidden`;
переход на Otter 0.8 требует отдельной миграции конфига.

Для пересборки: исходники официального тега
https://github.com/kuokuo123/otter-launcher/releases/tag/v0.7.3,
патч `scripts/patches/otter-launcher-0.7.3-hidden.patch` (`patch -p1` в корне
исходников), затем скопировать `scripts/patches/otter-launcher-0.7.3.Cargo.lock`
в `Cargo.lock` и выполнить `cargo build --release --locked`.
После проверки заменить бинарник в dotfiles и `~/.local/bin/`.

## Инструменты · 2026-10-17

Убраны placeholder поля ввода и нижняя подсказка. Старые t1/t90/t2/t30 заменены
одной командой timer. Команды с аргументом передают его через URL-кодирование:
выражения и пути не исполняются оболочкой.

| Команда | Использование |
| --- | --- |
| `calc` | Выражения и история. `calc 255 to hex`, `calc 10 km to m`. Результат копируется; `ans` используется при продолжении вычисления. Win+Shift+C открывает тот же калькулятор. |
| `ocr` | Выделить область мышью; текст rus+eng окажется в буфере. Esc отменяет. |
| `hex` | Выбрать файл или `hex /путь/к/файлу`. Просмотр xxd в nvim: адрес, hex, ASCII; буфер только для чтения. У больших файлов явно показано ограничение первых 16 МиБ. |
| `info` | Выбрать файл или указать путь. SHA-256, размер, формат/архитектура, энтропия и первые строки. Файл не запускается. Отчёт открывается в nvim. |
| `cc` | Локальный CyberChef v11.5.0 в браузере, включая необходимые assets. |
| `timer` | Меню длительности и отмены. `timer 25m`, `timer 1h30m`, `timer 05:30`. Без единицы число означает минуты; максимум 7 дней. |
| `recent` | Заметки из ~/notes/quick и Markdown в корне ~/notes, новые сверху; поиск по дате, названию и имени файла; Enter открывает в nvim. |
| `kill` | Свои процессы, CPU/RAM/время. TERM — обычное завершение; SIGKILL требует отдельно ввести PID. Проверяется идентичность процесса, сигнал отправляется через pidfd. |
| `rm` | Выбор явных пакетов (Tab — несколько), полный план с зависимостями и размером, затем подтверждение и штатный запрос pacman. |
| `ports` | Слушающие TCP/UDP-порты, адрес, процесс/PID; подробности, копирование адреса и завершение собственного процесса через то же меню TERM/KILL. |

Активный таймер виден в Polybar. Левый клик открывает управление,
правый отменяет. Новый таймер заменяет предыдущий; завершение даёт уведомление.
Таймер продолжает отсчёт по реальному времени во сне, уведомляет после пробуждения;
при перезагрузке таймер сбрасывается. Закрытие окна меню не отменяет таймер.

Калькулятор и его история используют ~/.local/state/otter-tools/.
Русская/английская модели OCR и CyberChef находятся в ~/.local/share/otter-tools/.
`otter-install-assets` скачивает официальные закреплённые версии и проверяет SHA-256;
вызывается установщиком dotfiles. Root для этих ресурсов не нужен.
Снимки OCR, hex и отчёты временные и удаляются после закрытия окна.

Проверки включают настоящий Qalculate, OCR rus+eng на синтетическом изображении,
hex в nvim без записи, сигнал TERM тестовому процессу, отказ от SIGKILL и удаления
пакетов, окончание/замену/отмену таймера. Рабочие процессы и пакеты в тестах не удаляются.

## Идеи, которые пока не добавлены

- `case`: папка исследования и шаблон отчёта.
- `diff`: выбрать два файла и сравнить текст, SHA-256 и hex.
- `hash`: сверить выбранный файл с введённой контрольной суммой.
- `qr`: QR из текста либо чтение QR с экрана.
- `img`: уменьшить или конвертировать копию картинки, очистить метаданные.
- `clip`: поиск в истории буфера Greenclip.

Отдельные программы для рассмотрения:

- ImHex: https://github.com/WerWolv/ImHex — структуры, шаблоны и редактирование бинарников.
- FLOSS: https://github.com/mandiant/flare-floss — извлечение обфусцированных строк.
- LocalSend: https://github.com/localsend/localsend — передача файлов между телефоном и ПК по локальной сети.
- ripgrep-all: https://github.com/phiresky/ripgrep-all — поиск в PDF, документах и архивах.
- hyperfine: https://github.com/sharkdp/hyperfine — сравнение скорости команд и скриптов.
- scrcpy: https://github.com/Genymobile/scrcpy — экран Android и управление с ПК.

Официальные исходники интеграций:
https://github.com/gchq/CyberChef, https://github.com/tesseract-ocr/tessdata_fast,
https://qalculate.github.io/.

## Закрытие окна Otter

Модули, запускающие отдельные окна (rm, kill, recent, hex, info, ports, timer,
calc, ocr, cc, note), запускаются с exec и перенаправлением всех трёх стандартных
потоков в /dev/null. Иначе дочерние процессы держат PTY Otter и Kitty не закрывает
исходное окно даже после выхода самого Otter. Для fo и yz это не применяется:
их интерактивный выбор использует терминал Otter.
Неподдерживаемая опция Kitty dynamic_background_color удалена.
Регрессия проверена в настоящих окнах Kitty на отдельном Xvfb-дисплее:
до исправления kill оставлял окно; после исправления kill/rm/recent/hex/info/ports/timer
закрывают исходное окно. Рабочие приложения и пакеты в тесте не изменяются.
