## Системные изменения подготовлены, требуют отдельного root-запуска

Команда: sudo ~/.local/bin/finish-workstation-audit

Скрипт хранится рядом с пользовательским окружением, его payload — Documents/Workstation/2026-10-18/system-repair/payload. Перед применением проверяет исходные файлы и SHA256 payload, работу NetworkManager и отсутствие участников br0/других managed-интерфейсов networkd. Делает root backup и Snapper-снимок, затем:

1. В runtime меняет только свою inet/filter; таблицы NAT/libvirt/Throne не перезапускает и весь ruleset не очищает. Из virbr1 к хосту разрешает DHCP, остальное блокирует; блокирует маршрутизацию virbr1 в обе стороны. Обычная сеть virbr0 сохраняется. Это не настройка сетевой лаборатории с эмулятором Интернета.
2. Архивирует старые bridge/static networkd-конфиги, выключает неиспользуемый networkd и wait-online, удаляет только пустой br0. Не перезапускает Ethernet, NetworkManager, iwd или Throne.
3. Включает мониторинг SMART, ежемесячный Btrfs scrub и уведомления об ошибках. Первый scrub запускается в фоне, с ограничением чтения 50 MiB/s. Его завершение нужно проверить по журналу; сам факт запуска не означает чистый результат.
4. Удаляет только wine и winetricks без рекурсивного удаления зависимостей; пользовательские префиксы остаются.
5. paccache сохраняет две версии, пакеты ядер/NVIDIA дополнительно исключены из этой очистки.

Скрипт не трогает драйвер, BIOS, сон, настройки LUKS/TRIM; не выполняет backup/upload, не перезагружает ПК. Его изменения считаются применёнными только после успешного вывода Completed. При ошибке часть предыдущих шагов могла завершиться.

Backup root: /var/backups/workstation-audit-*. В files/ прежние конфиги, service-state.json — исходное состояние служб. restore-filter.nft восстанавливает прежнюю inet/filter командой sudo nft -f /var/backups/.../restore-filter.nft; сначала оценить конкретную проблему. nft-before.txt — полный снимок для анализа, его не нужно загружать поверх работающих таблиц Throne/libvirt.
