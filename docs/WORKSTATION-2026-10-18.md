- **NVIDIA 580:** пакеты собраны, модули успешно скомпилированы для обоих ядер. Рабочий драйвер остаётся 470. Исходных пакетов 470 в кешах не было; 19 октября собраны семь пакетов из установленных файлов и проверена установка в отдельное временное дерево (554 файла, pacman -Qkk без изменений). Root-комплект завершён: /var/backups/nvidia470-recovery-20261019-074138, включая /boot/EFI. Изолированно проверены полная прямая транзакция 580 с тремя EGL-зависимостями и возврат к 470. В dotfiles подготовлены, но ещё не установлены системные изменения, сохраняющие callback-сон вопреки настройкам установщика 580. Реальная установка/загрузка GPU ещё не выполнялись. [NVIDIA-RECOVERY.md](NVIDIA-RECOVERY.md). restore-system.sh отказывается применять 470 payload поверх 580.
  Подготовлен nvidia-transition.py: по умолчанию только проверка, --apply580 для установки и --restore470 для возврата. Оба действия проверяют root-комплект и создают автономную закрытую копию помощника до транзакции; проверяются DKMS, initramfs, callback и EFI. 11 профильных тестов прошли. Нужен запуск --apply580 пользователем через sudo, затем отдельная ручная перезагрузка и проверка графики/сна.
- **LUKS/TRIM:** discard запрещён, fstrim.timer выключен. Для изменения нужна отдельная выбранная политика; текущая конфигурация сохранена.
