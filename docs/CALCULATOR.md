# Калькулятор для reverse engineering

Открыть: **Win+Shift+C** или `calc` в Otter. Обычные дроби, математика и
физические единицы работают через qalc. Для RE есть ограниченный целочисленный
парсер без `eval` и доступа к Python. Справка с примерами раскрывается в окне.

| Задача | Ввод | Результат |
|---|---|---|
| Байты → биты | `1 MiB to bits` | `8388608 bits` |
| Биты → байты | `32 bits to bytes` | `4 bytes` |
| Десятичные/двоичные единицы | `1 MB to KiB` | `976.5625 KiB` |
| HEX → DEC | `0xff to dec` | `255` |
| DEC → HEX | `hex(255)` | `0xff` |
| Двоичная запись | `bin(10)` | `0b1010` |
| Смещение адреса | `hex(0x5641f74a5000 - 0x2f000)` | `0x5641f7476000` |
| Signed, дополнительный код | `i32(0xffffffff)` | `-1` |
| Unsigned, обрезание | `u8(0x1234)` | `0x34` |
| Маска | `mask(12)` | `4095` |
| Число установленных битов | `popcount(u32(-1))` | `32` |
| AND / OR / XOR | `0xff & 0x0f` | `0xf` |
| Циклический сдвиг в 8 битах | `rol(0x81, 1, 8)` | `0x3` |
| Выровнять адрес вверх | `align(0x1001, 0x1000)` | `0x2000` |
| Упаковать little endian | `le(0x12345678, 4)` | `78 56 34 12` |
| Упаковать big endian | `be(0x12345678, 4)` | `12 34 56 78` |
| Распаковать байты | `fromle("78 56 34 12") to hex` | `0x12345678` |
| Обратить порядок байтов | `bswap32(0x12345678)` | `0x78563412` |
| HEX-байты → ASCII | `ascii("48 69 00")` | `Hi\x00` |
| Текст → байты UTF-8 | `utf8("Я")` | `d0 af` |

`B` — байты, `b` — биты. KB/kB/MB/GB используют 1000, KiB/MiB/GiB — 1024.
Доступны также TB/PB/EB и TiB/PiB/EiB, битовые варианты Kb/Mb/Kib/Mib и далее.
Можно писать `байт`, `бит`, `в` вместо `to`. Дробные байты сохраняются точно.

RE-операторы: `+ - * // % & | ^ ~ << >> **`. `^` здесь означает XOR;
степень — `**`. У `~` нет неявной ширины: `~0` = -1, `u32(~0)` = 4294967295.
Функции `u8/u16/u32/u64`, `i8/i16/i32/i64` явно обрезают число до ширины.
`rol/ror(value, shift, bits)` по умолчанию используют 64 бита; допускают 1–64.
В `le/be(value, size)` размер задаётся **в байтах**, переполнение вызывает ошибку.
Отрицательные значения упаковываются явно: `le(u32(-1), 4)`.

Два HEX-операнда сохраняют HEX-ответ. `to dec/bin/hex/oct` явно выбирает запись.
Signed-функции `iN` и `popcount` по умолчанию дают DEC. Под числовым ответом
показаны HEX/DEC/BIN; в буфер копируется только основной ответ.

Enter — вычислить; Ctrl+C — скопировать ответ без клика; выделенный текст
копируется обычным способом. Ctrl+Shift+C — всегда ответ. `ans` подставляет
предыдущий результат, Ctrl+L очищает ввод, Esc закрывает окно. История сохраняется.
Целые ограничены 4096 битами, длина ввода — 2048 символами.
