# Polybar · Black Tiffany

Оставлена одна панель — Tiffany Orbit, одинаковая для bspwm и AwesomeWM. Eww, AGS, прежний Polybar и встроенная панель Awesome удалены из активной конфигурации и установщика.

- **Win+Shift+B** — Control Deck: звук, яркость, инструменты анализа и повседневные действия. Ползунки применяют изменения без закрытия окна; Esc закрывает центр.
- **Win+P** — скрыть или показать Polybar.
- Звук на панели: колесо меняет громкость, ЛКМ включает / выключает звук, ПКМ открывает pavucontrol. Модуль PulseAudio сразу показывает состояние выбранного по умолчанию выхода, включая смену наушников.
- Музыка: ЛКМ — пауза / продолжить, ПКМ — следующий трек, колесо — предыдущий / следующий.
- CPU, RAM и температура открывают btop в полноэкранном Kitty. Если медиаплеер не сообщает трек, центр панели остаётся пустым. Сеть открывает nmtui, ПКМ — Throne.
- Приложения открываются на текущем рабочем столе. Автоматических назначений по приложениям нет.

Панель резервирует 44 px по высоте через X11 strut. Дополнительный top_padding не добавляется. В bspwm обычный window_gap остаётся 10 px; в Awesome одиночное тайловое окно начинается сразу под панелью, несколько окон сохраняют настроенный межоконный зазор.

```sh
panel-switch start   # запустить / перезапустить Polybar
panel-switch toggle  # скрыть / показать
panel-switch stop    # остановить
panel-switch        # открыть Control Deck
```

Основной конфиг: `~/.config/polybar/config.ini`. Control Deck: `~/.config/panel-lab/dashboard.js` и `dashboard.css`. Общие действия и показатели: `~/.local/bin/panel-action` и `panel-data`. Журналы: `~/.local/state/panel-lab/` (в Awesome — подкаталог `awesome/`).

GJS и GTK3 нужны для Control Deck и остаются установленными. Отдельные движки Eww и AGS больше не используются и не устанавливаются.

Otter запускает фоновые команды через `otter-run` с отдельной сессией и закрытыми дескрипторами старого терминала. Маршруты хранятся в `~/.config/otter-launcher/commands.json`, журналы — в `~/.local/state/otter-tools/launches/`. `cx` открывает Codex в новом Kitty, `note` — новую заметку в nvim; Discord не удерживает окно Otter.

Справа находится стрелка трея: значки скрыты по умолчанию, нажатие раскрывает их в панели, повторное нажатие скрывает. Используются штатные действия [Polybar module_toggle](https://polybar.readthedocs.io/en/stable/user/actions.html#all-modules).
