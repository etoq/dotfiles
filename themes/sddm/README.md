# SDDM Black Tiffany

Based on Void SDDM (Talyam); original metadata and README are retained in black-tiffany/.

Copy black-tiffany/ to /usr/share/sddm/themes/black-tiffany with root ownership and readable files. Set Current=black-tiffany in the active [Theme] SDDM configuration; /etc/sddm.conf overrides configuration directories. Back up the previous configuration first. The theme applies at the next login screen; restarting SDDM ends the current graphical session.

This theme changes appearance only. It does not configure PAM or install the workstation sleep settings.
